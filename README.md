# Shop Stock Manager

## Description

Shop Stock Manager is a command-line Python program designed to manage shop inventory efficiently.

The program allows the user to add stock, view current stock, record sales, refill shelves, monitor low stock, and generate an end-of-day sales report.

## Features

- Add new products and stock
- Set shelf capacity
- Set minimum shelf stock level
- View current stock
- Record product sales
- Detect empty shelves
- Detect low stock
- Suggest shelf refills
- Refill shelves from back stock
- Generate end-of-day report
- Display total products sold

## Requirements

- Python 3.x
- Command Prompt / Terminal
- No external Python libraries are required
