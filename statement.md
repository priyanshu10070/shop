# Shop Stock Manager

## Problem Statement

In a small shop, it can be difficult to keep track of how many products are available, how many are kept on the shelf, and how much stock is left in the back. If this is managed manually, the shopkeeper may forget to refill a shelf or may not notice when the stock is getting low.

To solve this problem, I created a **Shop Stock Manager** using Python. The program helps the user keep track of products, record sales, refill shelves, and check whether the stock is normal, low, or empty.

## Scope of the Project

The main purpose of this project is to make basic stock management easier for a small shop.

The program allows the user to:

* Add products and their stock details.
* Check the current stock of products.
* Record when a product is sold.
* Move products from back stock to the shelf.
* Check if the shelf is empty or has low stock.
* Get a refill suggestion when possible.
* View an end-of-day stock report.

This project is mainly made for learning and managing basic shop inventory. It is a console-based Python program, so it does not currently use a database or graphical interface.

## Target Users

This project can be useful for:

* Small shop owners.
* Shop employees who handle stock.
* Small retail stores.
* Students learning Python and basic inventory management.

It is mainly designed for shops that have a limited number of products and want a simple way to keep track of their stock.

## High-Level Features

### 1. Add Stock

The user can add a product and enter its total quantity, shelf capacity, shelf quantity, and minimum stock level.

### 2. View Stock

The user can see all the products and their current stock details, including shelf stock and back stock.

### 3. Record Sale

When a product is sold, the user can enter the quantity sold and the program automatically updates the remaining stock.

### 4. Refill Shelf

The user can refill the shelf using products available in the back stock. The program also checks whether there is enough space on the shelf.

### 5. Low Stock Warning

The program shows a warning when the shelf stock reaches or goes below the minimum stock level.

### 6. Empty Shelf Warning

If the shelf becomes empty, the program shows a warning and tells the user if back stock is available for refilling.

### 7. Refill Suggestion

When possible, the program suggests how many products can be moved from the back stock to the shelf.

### 8. End-of-Day Report

At the end of the day, the program displays the remaining stock, shelf stock, back stock, and the current status of each product.

### 9. Simple Menu

The project uses a simple numbered menu so that the user can easily select the required operation.
